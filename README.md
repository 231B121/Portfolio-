## ✨ Features

- **Light + Watercolor Aesthetic:** Soft ambient watercolor washes (sky blue, teal, lavender, and peach), subtle paper grain canvas, and refined translucent glass window interface.
- **Cambria Serif Typography:** Clean, elegant, and readable editorial serif typography powered by Cambria.
- **Interactive Folder Explorer:** Navigate through a full project hierarchy (`portfolio/` → `about/`, `experience/`, `projects/`, `credentials/`, `tech-stack/`, `connect/`).
- **Direct Resume Download:** One-click download of the latest official résumé (`Gourav_Ojha_Resume.pdf`).
- **Serene Watercolor Bloom Intro:** Gentle pigment dispersion intro with smooth transitions and instant skip option.
- **Fully Responsive:** Optimized touch-friendly mobile drawer and desktop multi-pane IDE layout.

## 🚀 Local Development

```bash
# 1. Clone the repository
git clone https://github.com/231B121/Portfolio-.git

# 2. Navigate to the project directory
cd Portfolio-

# 3. Install dependencies
npm install

# 4. Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

```bash
# Build for production
npm run build

# Start production server
npm run start
```
